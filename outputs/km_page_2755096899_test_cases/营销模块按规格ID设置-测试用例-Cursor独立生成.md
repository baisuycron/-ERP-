## 1. 测试范围

| 端/模块 | 覆盖内容 |
|---------|----------|
| 卖家侧-限时购 | 活动多商品、规格维度配置、列表查询、选择商品弹窗、商品详情、规格编辑、保存校验、详情只读、编辑限制、商品/规格终止撤出 |
| 平台侧-营销中心 | 限时购列表查询、活动时间筛选、规格ID查询、导出改造、详情只读 |
| 买家侧-PC/小程序 | 商品卡片价格、详情区间价、规格活动标识、限购报错文案、结算价 |
| 订单/库存 | 商品维度/规格维度活动库存扣减、未付款取消回退、付款后退款不回退 |
| 历史数据 | 上线前按商品/按规格限购活动字段映射 |
| 回归 | 商品规格调整限制、购物车/常购清单/批量下单、商品导入、ERP先货后款 |

**不在本期范围**：商品模块商品修改与导入逻辑本身不变（仅回归是否受影响）。

## 2. 测试前置条件

1. 卖家账号具备「营销 > 限时购」管理权限；平台账号具备「营销中心 > 限时购」查看/导出权限。
2. 准备多规格商品 A（规格 A1/A2/A3）、多规格商品 B（B1/B2）、单规格商品 C，均已上架且有库存。
3. 各规格商城价、库存可区分配置，便于校验价格区间与库存合计。
4. 买家账号可访问对应店铺，具备下单能力。
5. 可选：准备上线前的历史限时购活动（按商品限购、按规格限购各一条）。

## 10. 验收标准

1. 卖家可在一个限时购活动中配置多个商品，且同商品不同规格可参与不同限时购（规格级互斥）。
2. 限时价、限购、活动库存支持商品维度与规格维度配置，编辑态不可切换维度。
3. 买家侧 PC/小程序 价格、标识、限购文案与 PRD 示例一致。
4. 活动库存按 5.2 新规则扣减：未付款取消回退，付款后退款不回退。
5. 历史活动数据映射正确，无资损与错价。
6. 平台侧查询、导出满足新字段与新粒度要求。
